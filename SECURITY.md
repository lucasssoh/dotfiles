# Security

## Report a vulnerability

Report it privately, from the **Security** tab: [Report a vulnerability](https://github.com/lucasssoh/dotfiles/security/advisories/new). Don't open a public issue.

Say what is affected and how to reproduce it, with the output of `cc-pkg-mng --version`.

## Supported versions

Fixes go into the next release. Only the latest release gets them: `cc-pkg-mng upgrade` moves to it.
