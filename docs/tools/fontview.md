# Font viewer

Open a font file from the file manager, or run `fontview FILE`. In the cartoon look, it takes the [shell theme](../session/theme.md#nautilus-and-the-viewers)'s colours.

| Key | Does |
|---|---|
| `←` `→` | Previous or next font in the folder |
| `+` `−` | Changes the size |
| `q` | Quits |
