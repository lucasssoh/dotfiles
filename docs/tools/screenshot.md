# Screenshot

Take the screen or a region, annotate it, copy it.

## Take one

| Binding | Takes |
|---|---|
| `Super + S` | The whole screen |
| `Super + Shift + S` | A region you drag |

The Screenshot tile in [Balise](../bar/balise.md) takes one too. The shot opens in Screenshot, where you crop, draw arrows, write and blur.

| Key | Does |
|---|---|
| `Ctrl + C`, `Enter` | Copies the result |
| `q`, `Esc` | Closes |

In [swayimg](../apps/swayimg.md), `e` opens the image in Screenshot.

## Settings

| File | Sets |
|---|---|
| [`config/satty/config.toml`](../../config/satty/config.toml) | The annotation font, and the five colours of the palette |
| [`config/satty/overrides.css`](../../config/satty/overrides.css) | The window's look |
