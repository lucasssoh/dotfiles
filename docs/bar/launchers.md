# Launchers

Your open apps, as chips in the bar.

Click a chip to open its drawer:

| Row | Does |
|---|---|
| Focus window | Goes to the app's window |
| Open window | Opens another one |
| Close window | Closes the window |
| Quit app | Closes every window of the app |
| Force quit | Ends an app that no longer answers |

To start an app, use the [launcher](../tools/launcher.md).
