# swayimg

The image viewer. It opens images by default. Its settings are in [`config/swayimg/init.lua`](../../config/swayimg/init.lua).

| Key | Does |
|---|---|
| `←` `→` | Previous or next image in the folder |
| `Return` | Gallery, and back |
| `e` | Edits in [Screenshot](../tools/screenshot.md): crop, arrows, text, blur. Saved as `name-edit.png` next to the original |
| `f`, `[` `]` | Fullscreen, rotate |
| `q`, `Esc` | Quit |
