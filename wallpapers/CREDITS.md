# Credits

- `gnome-*`: GNOME's default background designs, from
  [GNOME/gnome-backgrounds](https://gitlab.gnome.org/GNOME/gnome-backgrounds),
  each in both variants. `gnome-<design>.jxl` is upstream's light one (`-l`)
  and `gnome-<design>-dark.jxl` its dark one (`-d`). They're kept as the
  original JPEG XL (`.jxl`), except the `gnome-morphogenesis*.jpg` pair:
  upstream only ships that design as SVG, so it's rasterized here at
  4096x4096. The light `.jxl` files are a bare JXL codestream and the dark
  ones use upstream's current ISOBMFF container. `jxl-oxide` reads both, so
  wallpaper-filter.rs and thumbs.rs need no change. They're licensed
  [CC BY-SA 3.0 US](https://gitlab.gnome.org/GNOME/gnome-backgrounds/-/raw/main/COPYING),
  and kept here under the same licence.
- All the `gnome-*` and `macos-*` (private repo) files use "fill" mode in
  wallpaper-filter.rs (plain cover and centre crop, no blur). See
  `prisme/wallpaper-fill-mode.conf`.
- `coucou-aube-*`: coucou-shell's own wallpapers (Plis, Soie, Relief),
  each in a light version (`coucou-aube-<name>.jxl`) and a dark one
  (`coucou-aube-<name>-dark.jxl`), generated by `coucou/make.py` at
  5120x3200 and encoded to JPEG XL with `cjxl`. The Relief pair is the
  default wallpaper on a new install. They're part of coucou-shell, under
  the project's licence.
- A file named `<name>-dark.<ext>` next to `<name>.<ext>` makes a pair:
  Prisme shows it as one wallpaper, and the desktop shows the half that
  matches light or dark mode. The GNOME and coucou sets are all pairs.
- Nothing else lives here, on purpose. Keeping only the GNOME set and
  coucou-shell's own wallpapers means the public repo carries a coherent
  collection whose licences are all known. Personal picks (and the
  `macos-*` files) live in `~/code/wallpapers-private`, which isn't public,
  and are merged into the same wallpaper folder at runtime through
  `prisme/wallpapers-extra.conf`.
